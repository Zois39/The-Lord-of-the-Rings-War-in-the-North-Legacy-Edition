# The Lord of the Rings: War in the North — Legacy Edition · Build Builder

Одностраничный некоммерческий билдер билдов для The Lord of the Rings:
War in the North (Legacy Edition). Чистый JS без фреймворков — откройте
`index.html` в браузере и пользуйтесь (или через GitHub Pages).

## Возможности

- **Герои**: Эрадан (Рейнджер), Андриэль (Хранительница знаний), Фарин (Чемпион Эребора).
- **Деревья навыков**: полные ветки с рангами, стоимостью (power),
  формулами роста и активными/пассивными умениями.
- **Атрибуты**: Strength / Will / Dexterity / Stamina — при повышении
  уровня даётся 3 очка атрибутов и 1 очко навыка.
- **Снаряжение**: оружие (ближний/дальний бой, посохи, щиты), броня по
  слотам и качеству, кольца и амулеты, камни-эльфы (слоты), сеты
  с бонусами за 2–6 предметов, мифриловые улучшения.
- **Подсветка требований**: уровень и атрибуты для экипировки.

## Источники чисел (формулы характеристик)

Точные коэффициенты выведены из стартовой статистики героев и перекрёстно
проверены:

- GameFAQs, The Lord of the Rings: War in the North — Guide and Walkthrough
  (FAQ 70985): стартовые HP/Power/атрибуты/урон трёх героев.
  Отсюда: HP = 50 + 5×Stamina; ближний урон = оружие + 2×Strength;
  дальний урон = оружие + 3×Dexterity; Power = база героя + 3×Will
  (база: Эрадан/Фарин 43, Андриэль 89 — классовая особенность лормастера).
- gametruth.com, «War in the North Legacy Edition Hero Build Guide» (2026):
  3 очка атрибутов + 1 очко навыка за уровень, кап уровня 40, направления
  атрибутов (Stamina → здоровье).
- Стартовые стрелы/болты — 40; Broad Quiver: +10 за ранг (описание навыка
  в вики).
- Спорные/оценочные данные (до подтверждения): точные пороги тиров навыков,
  стоимость power отдельных активных навыков (частично из вики-описаний).
  Числа отмечены тултипами в UI.

## Пробелы данных (честно)

- 18 полей в базе имеют значение «?» — сама вики их не знает (прочность,
  требования отдельных предметов). В UI они помечены «уточняется».
- Сетовая принадлежность: вики отмечает 8 предметов (+1 сопоставлено по
  имени). Полный список «предмет → набор» не восстановлен из источников.
- Русский пакет перевода (data/i18n/ru_desc.json): имена и описания —
  черновой перевод (src: "draft"). Русскоязычные первоисточники
  (гайды/форумы 2011–2013) будут прикручиваться по мере нахождения,
  найденное будет помечаться src: URL.
